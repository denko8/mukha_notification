## Производительность (раздел 6 ТЗ) — что заложено

- Стартовый экран рендерится из локального файла без сети.
- Лента — ленивый `ListView.builder`, новые карточки анимируются точечно.
- Парсер — синхронные regex без тяжёлых аллокаций, задержка ввода < 100ms.
- Снимок состояния иммутабельный, ребилды точечные через Riverpod.

## Безопасность (раздел 7 ТЗ)

- Локальные файлы лежат в приватном каталоге приложения.
- Проект Rules и разграничение семья/личное описаны в `BACKEND_SETUP.md`.
- Секреты в клиент не закладываются; весь серверный код — в Cloud Functions.
