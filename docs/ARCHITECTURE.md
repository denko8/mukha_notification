# Архитектура Smart Notes

## Принципы

1. **Offline-first.** Любая операция сначала применяется локально, затем
   помечается `pendingSync`. UI никогда не блокируется сетью.
2. **Feature-first структура.** Каждая фича (`notes`, `family`, `settings`)
   содержит свои `models / data / state / presentation`.
3. **Инфраструктура за интерфейсами.** UI знает только абстракции
   (`NotificationService`, `SyncService`, `JsonStore`). Боевые реализации
   (Firebase) подменяют провайдеры без правок экранов.
4. **Ноль кодогенерации в MVP.** Riverpod — классическими провайдерами,
   хранилище — JSON. Это сознательное решение для быстрого старта; миграция
   на Isar/Freezed не ломает архитектуру.

## Слои

```
Presentation (Widgets, ConsumerWidget/ConsumerStatefulWidget)
        │  читает/вызывает
        ▼
State (Riverpod AsyncNotifier: NotesNotifier, FamilyNotifier, SettingsNotifier)
        │
        ▼
Data (NotesRepository, FamilyRepository — бизнес-правила, персистентность)
        │
        ▼
Infrastructure (JsonStore, NotificationService, SyncService)
```

### Поток создания заметки

1. `NoteInputBar` на каждый ввод прогоняет текст через `NaturalDateParser`
   и рисует `Text.rich` с золотистыми span'ами.
2. По кнопке «Сохранить» `NotesNotifier.addFromText` ещё раз парсит текст
   (ручное напоминание имеет приоритет), берёт имя автора из настроек.
3. `NotesRepository.add` пишет заметку в `notes.json` и планирует
   локальное уведомление через `NotificationService.schedule`.
4. Состояние обновляется иммутабельно (`AsyncData`), новая карточка
   проигрывает slide-in 300ms ease-in-out, проигрывается системный звук.

### Поток напоминаний

- `flutter_local_notifications.zonedSchedule` в локальной таймзоне
  (`timezone` + `flutter_timezone`).
- При старте `main()` слушает загрузку заметок и вызывает
  `rescheduleAll` — отмена всех и планирование будущих ненажатых.
- Прошедшие даты не планируются. Удаление/выключение отменяет запись
  по стабильному `id.hashCode`.

### Парсер естественных дат (`core/utils/date_parser.dart`)

Чистый класс без зависимостей от Flutter, с инъекцией `now` —
полностью покрыт юнит-тестами. Порядок разбора:

1. относительные длительности (`через N часов/минут/дней`, в т.ч. составные);
2. ключевые слова (`сегодня/завтра/послезавтра`);
3. день недели (ближайший наступающий, никогда не сегодня);
4. число + месяц текстом (прошедшая дата без года → следующий год);
5. числовая дата `дд.мм[.гггг]`;
6. время (`14:00`, `в 7 вечера`, `в полдень/полночь`).

Результат — `DateParseResult(reminderDate, spans)`: момент для напоминания
и диапазоны для подсветки. Время по умолчанию — 09:00 (требование ТЗ).

### Семья

- `FamilyRepository` хранит членов семьи и инвайты в отдельных JSON-файлах.
- Инвайт: токен (8 символов uuid) → ссылка `https://smartnotes.app/invite/<token>`
  и QR. В боевой версии приём ссылки обрабатывает Firebase Dynamic Link.
- Вход по коду — локальная имитация серверного флоу, чтобы весь сценарий
  можно было протестировать без бэкенда.
- Заметка `isFamily = true` видна на вкладке Family и скрыта из личной ленты.

## Тестируемость

- `JsonStore` принимает каталог в конструкторе → тесты используют
  `Directory.systemTemp` без плагинов.
- `NoopNotificationService` проверяет факты планирования/отмены.
- `NaturalDateParser(now: ...)` детерминирован во времени.
