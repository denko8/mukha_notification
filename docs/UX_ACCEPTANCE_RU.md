# UX-полировка перед закрытой бетой

## Текущий этап

Backend и проверки на телефоне отложены по решению владельца продукта.
Без backend приложение не должно обещать облачную копию или обмен между телефонами.
Это ограничение текущей сборки, а не временное отсутствие интернета.

Сделано в первом проходе:
- вместо ложного «Синхронизировано» — честное описание локального хранения;
- локальный сервис не подтверждает отправку и не позволяет снять pendingSync;
- вместо приглашения на семейном экране — объяснение ограничения и способ передать заметку;
- пояснение семейного переключателя не обещает обмен между телефонами;
- сохранение защищено от повторного нажатия, есть индикатор;
- ошибка сохранения видима, черновик не очищается при ошибке операции;
- ошибка звука/вибрации не трактуется как ошибка сохранения.

## Второй проход: лента и поиск

- Первое открытие объясняет, где создать заметку, с примером фразы.
- Нет результатов поиска/фильтров — отдельное сообщение и сброс всех условий.
- Есть очистка строки поиска, число результатов и подписи кнопок поиска.
- Ошибка загрузки не выглядит как отсутствие заметок; доступен повтор.
- Прокрутка ленты закрывает клавиатуру; анимация появления учитывает
  системное отключение анимаций.
- Кнопка выполнения доступна через стандартный IconButton с подсказкой.
- Категории используют ChoiceChip (фокус, семантика выбора, стандартные нажатия).
- Статус карточки «На устройстве» вместо неоднозначного «Офлайн».
- Ошибка открытия системного шеринга на карточке видима пользователю.
- Добавлены widget-тесты пустых состояний (не запускались без Flutter SDK).
- Синтаксис lib/ и test/ проверен Tree-sitter Dart; это не заменяет анализатор Flutter.

## Пользовательский тест (5–8 человек, когда будет сборка)

Не показывать инструкцию заранее. Давать задания по одному:
1. Записать «Забрать заказ завтра в 14:00». Найти, на какое время поставлено напоминание.
2. Открыть заметку и изменить время.
3. Создать заметку без напоминания и найти её поиском.
4. Отметить дело выполненным, не открывая календарь.
5. Передать заметку родственнику. Объяснить, где она хранится и кто её видит.
6. Удалить ненужную заметку.

Фиксировать: выполнено без подсказки / с подсказкой / не выполнено,
время, ошибочные нажатия, слова пользователя. Не объяснять интерфейс за него.
Цель первого прогона — найти проблемы, а не доказать, что дизайн понравился.

## Отложенная проверка на устройствах

- Клавиатура, длинный текст, крупный системный шрифт, узкий экран.
- Голос: первое скачивание модели, отказ разрешений, остановка, автосохранение.
- Доставка уведомлений при заблокированном экране и после перезапуска.
- PDF с кириллицей, фото после перезапуска, системный шеринг.
- Светлая/тёмная тема и все палитры.
