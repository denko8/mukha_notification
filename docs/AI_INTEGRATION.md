# ИИ-распознавание желаний пользователя

Цель: вместо расширения жёстких правил модель понимает свободные формулировки
(«напомни, когда стемнеет», «позвони маме после работы», «как будет зарплата —
оплатить кредит»). Архитектура — **гибрид**, правила остаются навсегда.

## Почему гибрид, а не только LLM

| Требование | Только правила | Только LLM | Гибрид (реализовано) |
|---|---|---|---|
| Офлайн-работа (раздел 6 ТЗ) | ✅ | ❌ | ✅ правила работают без сети |
| Мгновенная подсветка при вводе (<100ms) | ✅ | ❌ задержка и токены на каждый символ | ✅ подсветка локальная |
| Свободные формулировки | ❌ | ✅ | ✅ LLM для сложных случаев |
| Нулевая стоимость по умолчанию | ✅ | ❌ | ✅ ИИ включается пользователем |
| Предсказуемость/тестируемость | ✅ | ❌ галлюцинации | ✅ фолбэк детерминирован |

## Компоненты

```
AiReminderParser (интерфейс)
├── RuleBasedAiParser   — NaturalDateParser + NoteClassifier, офлайн
└── LlmReminderParser   — облачная модель + автоматический фолбэк
                          при любой ошибке/таймауте/мусоре в ответе
```

Поток: `NotesNotifier.addFromText` → `aiParserProvider` → результат
(`reminderDate`, `category`, `summary`, `confidence`). Ручной выбор даты
и категории пользователем всегда имеет приоритет над моделью.
Подсветка дат в поле ввода по-прежнему считается локальным regex —
UI не зависит от доступности API.

## Формат запроса

Клиент `OpenAiCompatibleClient` работает с любым OpenAI-совместимым
`/chat/completions`: `response_format: json_object`, `temperature: 0.1`,
системный промпт задаёт жёсткую JSON-схему и правила семантики
(«к обеду» = 13:00 и т.д.). Ответ валидируется: ISO-дата, диапазон лет
2000–2100, категория из enum, confidence зажимается в 0..1.

## Провайдеры

| Провайдер | Доступность в РФ | Base URL (совместимый режим) | Модель для старта |
|---|---|---|---|
| YandexGPT | ✅ нативная | шлюз Yandex Cloud в OpenAI-режиме | yandexgpt-lite |
| GigaChat (Сбер) | ✅ нативная | собственный OAuth, нужен адаптер клиента | GigaChat Lite |
| OpenAI | через внешний прокси/VPN | `https://api.openai.com/v1` | gpt-4o-mini |
| Локальный Ollama | ✅ полностью офлайн | `http://<host>:11434/v1` | llama3.1:8b |
| Gemini (Google) | через прокси | OpenAI-совместимый эндпоинт Vertex | gemini-1.5-flash |

Пользователь вписывает Base URL, ключ и имя модели в Настройки →
«ИИ-распознавание». Ключ хранится только в локальных настройках устройства
и уходит исключительно на указанный URL.

## On-device вариант (без облака и ключей)

Для полной приватности вместо `LlmReminderParser` можно реализовать
тот же интерфейс поверх:

- **MediaPipe LLM Inference** (`mediapipe_genai`) — Gemma 2B/8B на Android,
  модель ~1.5–5 ГБ скачивается один раз;
- **llama.cpp через FFI** (`llama_cpp_dart`) — кроссплатформенно, тяжелее
  в интеграции.

Телефонные замеры: модель 2B выдаёт короткий JSON за 1–3 сек на среднем
Android, что приемлемо для разовой операции сохранения заметки.

## Приватность и экономика

- Фича выключена по умолчанию, включение — осознанный выбор с пояснением.
- В облако уходит только текст заметки и текущее время; ни вложения,
  ни профиль не отправляются.
- Логично сделать её преимуществом PRO (экран paywall уже есть):
  расходы на токены несёт владелец продукта.
- При любой ошибке сети/квоты/формата приложение бесшовно продолжает
  работать на правилах — деградация невидима для пользователя.
